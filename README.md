![What does it do](https://cdn.modrinth.com/data/cached_images/31094aa33a38945cfdb386bd0028260ed83275fc_0.webp)

- Drag a pack as a lifted card while the others slide aside and a placeholder marks its slot.
- Drop inside a list to re-order, or into the other list to enable or disable the pack at that exact position.
- Ctrl+click, Shift+click and Ctrl+A select several packs like in a file manager; drag them as one block.
- Dragging near a list edge scrolls it. Esc or a drop outside the lists glides the pack back.
- Pinned packs stay put, the Default pack is never disabled, and incompatible packs still ask for confirmation.
